1.
Si estas en windows tienes que instalar WSL primero con el comando:
wsl --install
y luego seguir las instalaciones de instalación, crear usuario y contraseña.
Si estas en Linux este paso no es necesario.

2.
Luego se debe instalar Homebrew con el siguiente comando (es igual para windows y Linux, pero en windows se debe instalar en la consola
dedicada de WSL, instalado en el paso anterior):
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

3.
Se debe instalar apache bench con los comandos(al igual que antes, windows en la consola de WSL, linux en su propia consola):
sudo apt update
sudo apt install apache2-utils

4.
Para realizar las pruebas se debe ejecutar el siguiente comando, asegurandose de cambiar ambas "x" con las correspondientes de su ipv4:
(antes de ejecutar el comando debe asegurarse de que el servidor este encendido)
ab -n 25 -c 5 http://192.168.x.x:7000/content
